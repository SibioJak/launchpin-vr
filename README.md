# LaunchPin VR

# ⬇️ [DOWNLOAD LAUNCHPIN VR](https://github.com/SibioJak/launchpin-vr/releases/download/1.1.6/LaunchPin_VR_Setup_1.1.6.exe)

**That link always gets you the latest version** — one file,
`LaunchPin VR Setup`. Run it and you're installing. (Windows will
stop it once because it isn't code-signed: **More info → Run
anyway**.)

A VR front end for Visual Pinball X. Put the headset on and your whole
VPX library stands on a wall in front of you — pick a table, play it,
and come back to the room when you're done, without ever taking the
headset off.

LaunchPin VR doesn't replace Visual Pinball — it drives it.

## What it does

- **The room** — your library as a wall of cards with the table
  authors' own artwork, favourites, filters, and search.
- **Scores in the room** — your PINemHi personal bests and boards
  stand next to the tables they belong to.
- **Tournament Room** — World of Virtual Pinball weekly boards in the
  room, and score submission from inside VR: take the screenshot,
  check the score it read back, submit.
- **The round trip** — exit a table and LaunchPin closes VPX and
  brings the room back. Hold the exit and everything shuts down.
- **Updates** — LaunchPin checks this repo's `version.json` at
  launch and tells you in the room when a newer version is here.

## What you need

- A Windows PC with Visual Pinball X (10.8 GL recommended) and your
  tables.
- A PCVR headset — developed and tested on Quest 3 over Virtual
  Desktop (VDXR).
- Optional: a PINemHi install for personal boards, a World of
  Virtual Pinball account for the Tournament Room.

## Download

The big link at the top of this page. It installs per-user — no
admin prompt — and the first run walks you through setup one step
at a time. The full manual is installed with the app (Start menu →
**LaunchPin VR Manual**).

## Bugs and feedback

Found something broken, or something that confused you? Open an
issue here: https://github.com/SibioJak/launchpin-vr/issues —
that's the fastest way to reach the developer, and it keeps every
report in one place. A screenshot and a sentence about what you
were doing when it happened help more than anything.

Some problems live in a table rather than in LaunchPin — the
[known table issues](KNOWN_TABLE_ISSUES.md) page lists the ones
confirmed so far, and what to do about them.

## Notes

LaunchPin VR is a one-person project, free. The source code lives
in a private repo; this repo is the public home for releases and
